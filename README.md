# Projetos+

Extensão do módulo nativo de Projetos do GLPI 10.

## Recursos iniciais

- Dados do Projeto: Cesta Portfólio e Ação PDTIC.
- Planejamento: Objetivo e Produto/Resultado esperado.
- Dados do solicitante: área, nome, e-mail, ponto focal e e-mail do ponto focal.

Os campos são opcionais e acompanham a entidade e as permissões do Projeto ao qual pertencem.

## Compatibilidade

- GLPI 10.0.20 a 10.0.99
- PHP 7.4+
